## Traversal 
<Tabs items={['Recursive DFT', 'Iterative DFT', 'BFT']}>
<Tab value="Recursive DFT">
```python
visited = set()

def dft(node: int) -> None:
    if node in visited:
        return

    visited.add(node)

    for nei in G[node]:
        dft(nei)
```
</Tab>

<Tab value="Iterative DFT">
```python
stack = [start]
visited = set()

while stack:
    node = stack.pop()
    if node in visited:
        continue

    visited.add(node)

    for nei in G[node]:
        stack.append(nei)
````
</Tab>

<Tab value="BFT">
```python
q = deque([start])
visited = set([start])

while q:
node = q.popleft()
    for nei in G[node]:
        if nei not in visited:
            visited.add(nei)
            q.append(nei)

```
</Tab>
